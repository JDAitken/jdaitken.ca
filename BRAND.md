# JD Media Brand Guide

## Positioning
JD Media is a "Digital Caretaker" for local service businesses. We build calm, premium, quietly technical experiences that reduce friction and turn clicks into confident calls. The brand energy is Clay-inspired: minimalist, precise, and understated.

## Voice
- Calm, clear, and grounded.
- Confident without hype.
- Helpful, caretaker tone.

## Usage Rules
- Prefer whitespace and restraint over decoration.
- Use the token system for every color, type, radius, and spacing decision.
- Prioritize readability and accessibility.
- Avoid flashy gradients, loud shadows, or aggressive marketing language.

## Color Palette
- Background: `#0F1115`
- Surface: `#161A22`
- Text: `#E6E8EE`
- Secondary text: `#A6ADBB`
- Muted text: `#7A8190`
- Border: `#242A36`
- Accent blue: `#5B8CFF`
- Muted teal: `#3FA9A0`

## Typography
- Primary: Inter (UI + body)
- Display: DM Sans (headings)
- Base size: 16px
- Tracking: slightly negative for headings

Font loading:
- Use Google Fonts or self-hosted files.
- If fonts are unavailable, the stacks in `styles/tokens.css` fall back to system fonts.

## Component Principles
- Buttons: clean pills, low elevation, clear focus rings.
- Cards: subtle surface contrast, minimal border, gentle radius.
- Forms: calm, high-contrast inputs with clear labels and focus states.
- Badges: quiet, informative, never loud.

## Do / Don't
Do:
- Use tokens for every value.
- Keep layouts airy and consistent.
- Favor clarity and calm.

Don't:
- Use heavy shadows.
- Stack multiple CTAs.
- Add noisy gradients or neon highlights.
